# S7 Expiração, Rate Limit e RLS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Automatizar a expiração de cotas, limitar reservas abusivas e auditar as permissões públicas do banco.

**Architecture:** Supabase Cron chama a função transacional de expiração a cada cinco minutos. As Server Actions transformam o IP da Vercel em HMAC e consomem um contador atômico no Postgres antes de criar convidados ou claims.

**Tech Stack:** Next.js 16 App Router, TypeScript, Supabase Postgres/pg_cron, Vitest.

## Global Constraints

- Limite global de 5 reservas por IP em 60 segundos.
- IP puro nunca é persistido ou retornado.
- `guests`, `claims` e contadores não têm acesso público.
- Dinheiro e transições de cotas continuam atômicos.
- Nenhum serviço, pacote ou conta adicional.
