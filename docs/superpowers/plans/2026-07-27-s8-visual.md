# S8 Visual e Conteúdo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar a experiência pública em um convite editorial completo, adicionar `/nos` e tornar a contagem regressiva testável, responsiva e leve.

**Architecture:** A home e `/nos` permanecem Server Components estáticos, com uma ilustração vetorial reutilizável. Somente `Countdown` hidrata no navegador e delega o cálculo a uma função pura. O catálogo continua vindo do Supabase e as fotos cadastradas continuam usando `next/image`.

**Tech Stack:** Next.js 16.2.12 App Router, React 19, TypeScript, CSS global/Tailwind 4, Vitest, Supabase.

## Global Constraints

- Manter direção A: Cormorant Garamond + Jost, marfim `#FBF7F0`, marsala `#964F4C`.
- Mobile-first e utilizável no navegador interno do WhatsApp em 4G.
- Não adicionar dependências, mapa incorporado ou animação JavaScript.
- Não inventar fatos pessoais, dress code ou imagens do casal.
- Não alterar fluxos de presentes, PIX, RSVP, mural ou admin.
- Ler a documentação local do Next.js 16 antes de alterar APIs de imagem/fonte.
